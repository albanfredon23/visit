# Visite 3D · Alban Fredon

Une pièce en 3D où l'on se promène librement (ZQSD/WASD, flèches, souris ou joystick tactile). Sur l'écran de l'ordinateur défilent mes projets GitHub (Aiogps, AIOTECH MCP, AIOTECH Search, AIOTrade, AIOBot, AIO v3), chacun avec les éléments 3D et les couleurs de son propre site ; en cliquant dessus, on plonge dans l'écran pour les faire tourner. La visite se termine par ma fiche tarifaire et mes coordonnées. Le lien `#tarifs` ouvre directement la fiche tarifaire.

**En ligne : https://albanfredon23.github.io/visit/**

- Three.js, sans framework ni étape de build : `index.html`, `css/`, `js/` (modules).
- Textes, projets, prix et contact en français et en anglais : `js/data/content.js`.
- Une scène par projet : `js/gallery/projects/`.
- Qualité graphique adaptative : le rendu s'allège tout seul si l'appareil ralentit.

Pour lancer en local : `npx http-server .` puis ouvrir http://localhost:8080.
