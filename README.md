# Visite 3D · Alban Fredon

Une pièce en 3D où l'on se promène librement (ZQSD/WASD, flèches, souris ou joystick tactile). Sur l'écran de l'ordinateur défilent mes créations 3D ; en cliquant dessus, on plonge dans l'écran pour les faire tourner. La visite se termine par ma fiche tarifaire et mes coordonnées.

**En ligne : https://albanfredon23.github.io/visit/**

- Three.js, sans framework ni étape de build : `index.html`, `css/`, `js/` (modules).
- Textes, créations, prix et contact en français et en anglais : `js/data/content.js`.
- Qualité graphique adaptative : le rendu s'allège tout seul si l'appareil ralentit.

Pour lancer en local : `npx http-server .` puis ouvrir http://localhost:8080.
